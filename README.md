# Illuminons AI Scheduler

MVP demonstrativo da Illuminons IT para apresentação comercial.

## Funcionalidades

- Dashboard
- Clientes
- Agendamentos
- Produtos/Serviços
- Simulação de chatbot com IA
- Configurações

## Como rodar localmente

```bash
npm install
npm run dev
```
